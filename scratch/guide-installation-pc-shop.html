MAXI EQUIP · Procédure d'installation

Installer l'application sur le PC Shop

Guide complet, à suivre dans l'ordre. Toutes les valeurs à copier sont déjà remplies ci-dessous — aucune information supplémentaire n'est nécessaire pour terminer l'installation.

📦 Avant de commencer

Un seul fichier est nécessaire, à récupérer auprès de la personne qui vous a transmis ce guide :

  • MAXI EQUIP Setup 0.1.0.exe — l'installeur
Confidentiel

🔒 Cette page contient des identifiants réels

Ne partagez ce lien qu'avec la personne qui installe l'application. Une fois l'installation terminée, cette page peut être fermée définitivement.

1

Désactiver Smart App Control (si Windows le demande)

Si Windows bloque l'installation à l'étape suivante : ouvrez Sécurité Windows → Contrôle des applications et du navigateur → Paramètres de contrôle des applications intelligent → réglez sur Désactivé.

Ignorez cette étape si l'installation à l'étape suivante se déroule sans blocage. L'installeur n'est pas signé numériquement — c'est normal, Windows peut afficher un avertissement "éditeur inconnu" : cliquez Informations complémentaires puis Exécuter quand même.

2

Installer l'application

Lancez MAXI EQUIP Setup 0.1.0.exe et suivez l'assistant jusqu'au bout. Ne lancez pas encore l'application à la fin de l'installation.

3

Configurer les variables d'environnement

Méthode recommandée : un script qui configure les 7 variables d'un coup, sans risque d'erreur de frappe.

PowerShell — à exécuter en Administrateur 
$vars = @{
  "MAXI_EQUIP_API_URL"="https://api.maxi-equip.com";
  "MAXI_EQUIP_SYNC_JWT"="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJzaG9wLTEiLCJyb2xlIjoiYXBwIiwiaWF0IjoxNzkwNjQ2MzY2LCJleHAiOjE4MjIxODIzNjZ9.nOyAKxljMPienCHPFvK__CK_kQzAzVvY9HKRqZd7mcE";
  "CLOUD_BACKUP_BUCKET"="maxiequip-backups";
  "CLOUD_BACKUP_REGION"="eu-central-003";
  "CLOUD_BACKUP_ENDPOINT"="s3.eu-central-003.backblazeb2.com";
  "CLOUD_BACKUP_ACCESS_KEY_ID"="0033c5495a5247f0000000006";
  "CLOUD_BACKUP_SECRET_ACCESS_KEY"="K003KkD73Ma/v/m/Ar7Z5fp0VwlkKoQ"
}
$estAdmin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
if (-not $estAdmin) {
  Write-Host "Ce script doit etre execute en Administrateur. Fermez cette fenetre, puis :" -ForegroundColor Red
  Write-Host "clic droit sur le bouton Demarrer -> Terminal (Admin) -> recollez le script." -ForegroundColor Red
} else {
  foreach ($n in $vars.Keys) { [Environment]::SetEnvironmentVariable($n, $vars[$n], "Machine") }
  Write-Host "Les 7 variables ont ete configurees." -ForegroundColor Green
  Write-Host "Redemarrez l'ordinateur maintenant avant de lancer MAXI EQUIP." -ForegroundColor Yellow
}

Ouvrez PowerShell en Administrateur (clic droit sur le bouton Démarrer → Terminal (Admin) ou Windows PowerShell (Admin)), collez le script copié, appuyez sur Entrée, puis redémarrez l'ordinateur avant l'étape 5.

Méthode manuelle (si le script ne peut pas être utilisé)

Tapez variables d'environnement dans le menu Démarrer → ouvrez Modifier les variables d'environnement système → bouton Variables d'environnement… → dans la section du bas, Variables système, cliquez Nouvelle… pour chacune des 7 lignes ci-dessous.

Une fois les 7 variables créées, cliquez OK sur chacune des fenêtres ouvertes pour tout enregistrer, puis redémarrez l'ordinateur.

4

Premier lancement — créer le compte Administrateur

Lancez MAXI EQUIP. À l'écran de configuration initiale, choisissez Nouvelle installation et créez le compte Administrateur.

Le mot de passe choisi ici protège tout : c'est lui qui permettra de tout récupérer automatiquement si ce PC est un jour remplacé. Choisissez-en un solide, et transmettez-le au propriétaire par un canal sécurisé (jamais par ce lien).

5

Redémarrer l'application une fois

Fermez complètement MAXI EQUIP puis relancez-la. Ce redémarrage déclenche la toute première sauvegarde automatique — utile pour confirmer que tout fonctionne.

C'est terminé de votre côté

Aucune autre configuration n'est nécessaire. La vérification finale (synchronisation, sauvegarde cloud) se fait à distance, côté serveur — vous n'avez rien de plus à faire.

En cas de blocage à une étape, notez le numéro de l'étape et le message affiché à l'écran.
